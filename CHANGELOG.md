# Pinky Promise Website Changelog

This document records the changes made to the Pinky Promise website.

## Version 3.0.0 - 30 October 2026

### JavaScript Enhancements
- Added automatic copyright year functionality.
- Implemented live product search.
- Added a message for searches with no matching products.
- Added an interactive FAQ accordion.
- Added contextual hints to the enquiry form.
- Implemented client-side form validation.
- Added error messages for invalid form inputs.
- Added an image lightbox for viewing nail designs.
- Added scroll reveal animations.

- Added page-specific title tags.

- Added descriptive alternative text to images.
- Improved internal links between website pages.
- Created robots.txt.

- Added keyboard focus indicators.
- Improved form feedback messages.
